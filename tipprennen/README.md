# Tipprennen

Medienbildung / Tastaturschreiben: Texte so schnell und genau wie möglich abtippen – allein oder als Live-Rennen mit der ganzen Klasse.

- **Üben:** allein gegen drei Computer-Tiere (Tempo langsam/mittel/schnell), funktioniert ohne Internet.
- **Rennen leiten (Lehrkraft):** Raum öffnen, 4-stelliger Raum-Code erscheint groß am Beamer, Thema und Länge wählen, Rennen starten und live verfolgen.
- **Rennen beitreten (Klasse):** Code eingeben, Spitzname wählen (Zufallsname möglich) – keine echten Namen.
- **Themen:** Grundgesetz, Tastatur, Ordner und Dateien, Sicher im Internet, Künstliche Intelligenz, Datenschutz – oder alles gemischt.
- **Auswertung:** Zeichen pro Minute, Genauigkeit, Zeit, Platzierung; Einfügen ist gesperrt, Fehler werden rot markiert.

- **Live:** https://schulapplikationen.github.io/physik-apps/tipprennen/
- **QR-Code für die Klasse:** `qr_tipprennen.png`
- **Aktuelle Version:** `index.html` (Stand 2026-11-05, Fassung 01)
- **Versionen:** Ordner `versionen/` – jede Fassung als `JJJJ-MM-TT_NN_tipprennen.html`, die neueste ist identisch mit `index.html`.

Datenschutz: Der Übungsmodus läuft komplett im Browser. Nur für Live-Rennen wird die Bibliothek PeerJS (unpkg.com) geladen; die Geräte verbinden sich über den PeerJS-Vermittlungsserver direkt miteinander. Übertragen werden nur Spitzname und Rennfortschritt, gespeichert wird nichts.
